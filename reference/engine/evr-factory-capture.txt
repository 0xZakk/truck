EGR Electronic Vacuum Regulator Solenoid: Description and Operation EGR Vacuum Regulator (EVR) Solenoid: PURPOSE The EGR Vacuum Regulator ( EVR ) solenoid is an electromagnetic device which controls vacuum output to the EGR valve . OPERATION The Powertrain Control Module (PCM) outputs a duty cycle to the EVR which regulates the vacuum level to the EGR valve .  As the duty cycle is increased, so is the vacuum signal to the EGR valve.  The vacuum source is manifold vacuum.
