After the visual inspection and symptom chart, cruise diagnosis routes into a set of lettered
pinpoint tests, each targeting one distinct complaint. The FSM's set for this truck is:

- A — Speed Control Inoperative
- B — No Power to Servo
- C — No Power on Deactivator Switch
- D — Steering Wheel "On" Switch Inoperative
- E — Speed Control Surges
- F — Coast/Tap-Down Function Inoperative
- G — Accel/Tap-Up Function Inoperative
- H — Resume Function Inoperative
- J — Speed Control Does Not Disengage When Brakes Applied
- K — Speed Control Will Not Turn Off With "Off" Switch

Matching the customer's exact symptom to the right letter is the whole point: a function-specific
complaint (resume, coast, accel) has its own test and usually its own switch contact, while
"inoperative" or "no power" complaints (A, B, C) point at power and servo circuits. The
step-by-step tables themselves are delivered as scanned images in the FSM, so this note
captures the index that tells you which test to open on the `electrical-body` system.
