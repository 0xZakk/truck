The 1994 F-150's backup (reverse) lamps are switched differently depending on the
transmission. With a manual transmission a dedicated backup lamp switch provides voltage to
the backup lamps whenever the gearbox is in reverse. With the C6 automatic the park/neutral
position switch lights them in REVERSE, and with the E4OD or 4R70W automatics the manual
lever position sensor — the transmission range (TR) sensor — performs the same job.

This matters when diagnosing dead reverse lights: on a manual the suspect is a simple
gearbox-mounted switch, but on an automatic the culprit is the same range/PNP switch that
the starting and transmission-control systems also rely on. This is part of the truck's
`electrical-body` system.
