On the 4.9L the engine-position signal is generated by a Hall-effect switch in the distributor,
not a crankshaft sensor. The Camshaft Position (CMP) sensor uses a 6-bladed shutter plate,
driven by the camshaft, that rotates through the gap of the stator pickup. When a vane enters
the gap it distorts the magnetic field and turns the Hall output ON; when the vane leaves, the
field returns and the output turns OFF. The result is a clean square wave that alternates between
0.0 and 12.0 V — the raw input to the Profile Ignition Pickup (PIP) signal. Each blade
corresponds to a crankshaft position.

This one signal is the backbone timing reference. The Ignition Control Module (ICM) reads the
raw Hall output and converts it into the PIP signal sent to the PCM, which derives crankshaft
position, base timing, and engine speed (rpm) from it. The PCM then uses PIP both to time the
spark (calculating ignition advance and dwell) and to time fuel injection — so a single
distributor sensor underpins both the `ignition` and `fuel` systems, and losing PIP loses spark
and injection timing together.

For diagnostics this is the heartbeat: lose PIP and the engine won't run, because the PCM has no
position reference. A 12 V square wave on a scope, scaling cleanly with cranking and running
speed, is the signature of a healthy sensor. Spec checks: PIP at KOEO reads >8.0 V DC with the
Hall switch shut, and 3.0–8.5 V AC while cranking.
