On this OBS F-150, the `fuel` filter is mounted along the frame rail on the driver's side, just
ahead of the rear wheel. The owner found it a pain to remove because the spring-lock fuel-line
fittings will not release with the common straight push-style disconnect tool — they need the
small **curved** plastic fuel-line disconnect tools (a set of different sizes; he found the blue
one fit his lines). Buying the wrong tool first is an easy and common mistake.

This is a maintenance/access detail rather than a diagnosis: in this video, replacing the fuel
filter did **not** cure the rough idle, so the value here is knowing the filter's location and the
correct tool before attempting the job. Because the EFI system runs at high pressure, relieve fuel
pressure before opening a line, and pair a filter change with a fuel-pressure test if you actually
suspect fuel-delivery starvation.
