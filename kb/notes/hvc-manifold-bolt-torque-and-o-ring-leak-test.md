A refrigerant leak at the manifold (suction/discharge line block) on the 1994 F-150
compressor (inventory id `hvac`) is often just an under-torqued bolt rather than a bad seal.
The FSM procedure is to first torque the manifold bolt to 13–17 ft lb and add refrigerant if
needed, then leak-test the manifold O-ring seals with a halogen leak detector.

Only if a leak is still found with the bolt correctly torqued to 13–17 ft lb does the FSM
direct you to install new manifold O-ring seals and repeat the leak test. This order — torque
first, reseal second — avoids needlessly tearing into the joint.
