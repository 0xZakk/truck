## Summary

This page consolidates the 4.9L base timing specification, the octane-adjust (spark-out / SPOUT
shorting bar) connector, and the engine firing order. Base ignition timing is 10° BTDC. Because
the EEC-IV/distributorless logic computes spark, an in-line octane-adjust connector with a
shorting bar lets a technician trim timing for fuel quality.

The octane switch retards ignition timing approximately three degrees to reduce detonation when
lower-grade fuels are used. With the jumper INSTALLED, computed timing is normal; with the jumper
REMOVED, computed timing is retarded by roughly three degrees, trading some advance for knock
resistance. The 4.9L I6 firing order is 1-5-3-6-2-4. These facts together let you set base timing
and reason about spark behavior on the `engine` system.

## Key Points

- Base timing: 10° BTDC.
- Firing order: 1-5-3-6-2-4.
- Octane-adjust connector uses a shorting-bar jumper.
- Jumper INSTALLED = normal computed timing.
- Jumper REMOVED = timing retarded approximately 3 degrees to reduce detonation on lower-grade fuel.
