## Summary

The 2WD F-150 front hubs ride on tapered roller bearings whose preload is set by hand with a
specific seat-then-back-off-then-snug sequence. After pushing the disc brake pads back to get
running clearance (without prying the phenolic caliper piston), the adjusting nut is torqued
to seat the bearings, backed off about half a turn, then re-snugged to a very light final
torque while spinning the rotor. The result is checked against an end-play window and a
rotating-torque window before the cotter pin and grease cap go back on.

This source consolidates the Wheel Bearing Adjustments procedure and the Wheel Bearing
Specifications for the `suspension` system.

## Key Points

- Seat bearings: tighten adjusting nut to 23-34 Nm (17-25 ft lb) while rotating rotor.
- Back the nut off about one half turn.
- Final snug: tighten to 2.03-2.26 Nm (18-20 IN lb) while rotating rotor.
- Resulting end play: 0.006-0.127 mm (.00025-.005 in).
- Torque to rotate the hub should be 1.13-2.82 Nm (10-25 in lb).
- Push pads back for running clearance; do NOT pry on the caliper phenolic piston.
- Always install a NEW cotter pin and bend both ends around the retainer.
