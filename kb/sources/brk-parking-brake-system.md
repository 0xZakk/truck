## Summary

Each rear wheel brake assembly contains a cable-actuated parking brake mechanism. A release handle is built into the parking brake control (2780). These control assemblies are self-adjusting and require no adjustment. (When the rear drum shoes are serviced, the rear parking-brake cable and conduit should still be checked for proper adjustment and the equalizer verified to operate freely.)

## Key Points

- Parking brake is cable-actuated through the rear (drum) wheel brake assemblies.
- Release handle is integral to the parking brake control (2780).
- Self-adjusting — no parking-brake adjustment is specified.
- During rear brake service, verify the rear cable/conduit (2A635) and that the equalizer moves freely.
