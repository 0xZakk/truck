## Summary

This consolidates the 4.9L tune-up reference values and the compression test procedure.
The firing order is 1-5-3-6-2-4. Spark plug electrode gap is 0.042-0.046 in. Base
(initial) ignition timing is 10 degrees BTDC. These are the core numbers needed for a
basic ignition tune-up on the 300 I6.

Compression is tested with the engine warm and throttle held wide open: remove all spark
plugs, install a compression gauge in No. 1, crank at least five compression strokes with
an auxiliary starter switch (key off), record the highest reading, and repeat per cylinder.
Ford does not publish an absolute cranking pressure; instead, the engine passes if the
lowest-reading cylinder is within 25% of the highest. A spread over 25% points to an
improperly seated valve or worn/broken rings.

This source backs the `engine` inventory system.

## Key Points

- Firing order: 1-5-3-6-2-4.
- Spark plug gap: 0.042-0.046 in.
- Base ignition timing: 10 degrees BTDC.
- Compression test: warm engine, plugs out, throttle wide open, crank 5+ strokes per
  cylinder with an auxiliary starter switch (key off), record highest reading.
- Pass criterion: lowest cylinder within 25% of the highest; >25% spread = bad valve seat
  or worn/broken rings.
