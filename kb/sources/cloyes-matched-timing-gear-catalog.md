## Summary

PDF page 13 lists matched set 8-1014 for Ford inline-six engines from 1965 through 1996, with a steel crank gear and aluminum cam gear. This is a replacement-set reference, not identification of the gears installed in the owner's truck.

The row provides no tooth count, helix angle, dimensions or displacement. The product photos above it are generic examples without individual Ford part labels. They must not be used as exact Ford geometry. This reference does not close the model's provisional timing-gear dimensions.

## Key Points

- Confirm displacement-specific application before using this replacement set as a model target.
- Retain uncertainty about installed materials, tooth geometry and timing indexing.
