## Summary

What turns on the 1994 F-150's backup (reverse) lamps depends on which transmission is
fitted, and the FSM splits the backup lamp switch into three transmission variants. With a
manual transmission a dedicated backup lamp switch provides voltage to the backup lamps when
the gearbox is in reverse. With the C6 automatic the park/neutral position switch does the
job, and with the E4OD or 4R70W automatics the manual lever position sensor (transmission
range / TR sensor) does it.

On both automatics the same switch/sensor does double duty: in REVERSE it lights the backup
lamps, while in PARK or NEUTRAL it directs current to close the starter motor relay — which
is why a faulty range switch can simultaneously kill the reverse lights and the starter.
This component is part of the truck inventory system `electrical-body`.

## Key Points

- Manual transmission: a dedicated backup lamp switch supplies voltage to the backup lamps when in reverse.
- C6 automatic: the park/neutral position switch lights the backup lamps in REVERSE.
- E4OD / 4R70W automatics: the manual lever position sensor (TR sensor) lights the backup lamps in REVERSE.
- On both automatics, the same switch/sensor closes the starter motor relay in PARK or NEUTRAL.
- This shared role means one failed range switch/sensor can disable both the reverse lamps and engine cranking.

## Notable Excerpts

> "With Manual Transmission ... With the transmission in reverse, the backup lamp switch
> provides voltage to illuminate the backup lamps."

> "With C6 Transmission ... With the transmission in 'REVERSE', the park/neutral position
> switch directs current to illuminate the backup lamps. With the transmission in 'PARK' or
> 'NEUTRAL' the park/neutral position switch directs current to close the starter motor relay."

> "With 4R70W and E4OD Transmissions ... With the transmission in 'REVERSE', the manual lever
> position sensor directs current to illuminate the backup lamps."
