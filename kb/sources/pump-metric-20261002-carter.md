The manufacturer's separate application catalog identifies W9046M for1993–1996 F1504.9L. The datum is engine mounting face to pulley mating face, as explained in [[sources/online-heater-carter-hub|Carter hub-height datum]]. It excludes projecting pilot length. No hub outside diameter is provided. Thread metadata contains a malformed mixed-unit designation and is not adopted.
