## Summary

The 1994 F-150 A/C system (inventory id `hvac`) is diagnosed by reading refrigerant pressures
and the compressor clutch cycle rate and time, then comparing those against the FSM's normal
pressure/temperature and clutch-cycle charts. Readings outside the chart bands are looked up
on the A/C System Evaluation Charts to pinpoint the faulty component. A visual inspection
catches obstructed air passages, broken wires, loose brackets, and leaks.

This source consolidates the System Performance Test, Refrigerant System Pressure Evaluation
Chart, Normal Pressure/Temperature Relationship, and Normal A/C Compressor Clutch Cycle Rates
pages. (The actual chart values are FSM figures/images, not text.)

## Key Points

- Diagnose by comparing measured pressures and clutch cycle rate/time to the normal charts;
  conditional test requirements must be met for the readings to be valid.
- If readings fall outside the chart bands, use the A/C System Pressure Evaluation Charts
  (A and B) for component diagnosis.
- After repair, re-take readings under the same conditions to confirm the fix.
- A refrigerant leak usually shows as an oily residue at the leak point.
- Normal pressure/temperature and clutch-cycle data are provided as charts (images) rather
  than tabular text in this FSM.

## Notable Excerpts

> "Refrigerant system problems are diagnosed by checking refrigerant pressures and clutch
> cycle rate and times. Compare pressures and cycle time to charts shown. ... If findings do
> not fall between lines of respective charts, refer to A/C System Evaluation Chart to
> determine cause of improper readings."

> "NOTE: A refrigerant leak will usually appear as an oily residue at the leakage point in the
> system."
