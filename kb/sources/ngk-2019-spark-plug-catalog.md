## Summary

The F-150 application table on PDF page 143 (printed page 140) lists WR4-1, stock number 4652, for 1993–1994 trucks with the 4.9L inline-six. The application gap is .044 inch, within the archived Ford manual's .042–.046 inch range. Adjacent bi-fuel applications have different gap entries and must not be merged with this row.

The dimensional table on PDF page 63 (printed page 60) places WR4-1 in the 18 mm thread group, with .460 inch reach, 13/16 inch hex, extended projection and a tapered seat. These are replacement-part envelope facts; they do not establish the brand or condition of the plugs currently installed in the owner's truck. Insulator lengths, internal resistor construction and thread pitch remain to be established.

## Key Points

- WR4-1 / 4652 is an explicit application match.
- Reach converts to 11.684 mm; hex across flats to 20.6375 mm.
- This row uses a tapered seat, not the loose-gasket design in the neighboring row.
- Profile image 143 and tip image DH are referenced on the next catalog page.
