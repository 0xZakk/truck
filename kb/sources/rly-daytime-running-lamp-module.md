## Summary

The Daytime Running Lamp (DRL) Control Unit operates the high-beam headlamps at reduced intensity
during daylight driving. With the ignition switch in RUN, the parking brake released, and the
headlamps turned off, the DRL module outputs a pulsing voltage to run the high-beam headlamps at
reduced intensity.

A diode inside the module prevents a low brake fluid level condition from disabling the DRL
system. This detail matters during diagnosis: a low-brake-fluid signal sharing wiring with the
park-brake input does not knock out the DRLs because of the in-module diode.

## Key Points

- DRLs operate only with ignition in RUN, park brake released, and headlamps off.
- The module pulses voltage to run the high beams at reduced intensity.
- An internal diode keeps low brake fluid level from disabling the DRL system.
- This lighting module is part of the `electrical-body` lighting distribution.
