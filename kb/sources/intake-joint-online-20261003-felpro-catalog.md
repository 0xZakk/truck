The manufacturer catalog's model index PDF305/printed279 lists F1502WD4.9L VINY for1987–96. Engine table42, PDF354/printed328, lists MS93838 as the upper plenum gasket set for1991–97 Ford truck4.9MFI gasoline VINY.
