# Token-efficient truck reconstruction

The objective remains a detailed, source-supported component reconstruction with individual pages, coherent assembly, useful motion, explanations and troubleshooting. Cost reduction must not turn approximate geometry into accepted production geometry or remove visual, dimensional, contact, clearance or browser checks.

## Audit baseline

The 2026-09-26 cost snapshot records 5,730 model calls across two main tasks and eight worker sessions, averaging 130,526 input tokens per call. Cached input accounts for $733.67 of the $985.96 standard-rate counterfactual. This is evidence of a large context expense, not proof that every included token was unnecessary. Detailed audit: `cost-estimates/2026-09-26-efficiency-audit.json`.

## Working method

1. Maintain one concise current-state record, with the authoritative working directory, manifest hash, accepted results, pending process handles and next dependency. Historical failures stay in an archive linked from it. Replace stale current-state statements rather than appending contradictory updates indefinitely.
2. Delegate independent assemblies using fresh agent context (`fork_turns="none"`) and a focused brief: objective, relevant source pages, coordinate/interface contract, owned files, known rejected approaches and required acceptance checks. References remain in files and are retrieved on demand. Retain full model capability for geometry and engineering judgment.
3. Agree on evidence and interface constraints before detailed geometry: source dimensions, production applicability, attachment datums, passage connections and unavailable facts. Review the candidate silhouette against photographs before expensive whole-engine audits. Resolve wrong constraints upstream rather than polishing a known-wrong envelope.
4. Run deterministic build/check/report sequences as local programs. Retain full logs on disk; give the model compact failure summaries, changed artifacts and evidence hashes. Use bounded event/process waits, and combine independent reads. The model should solve failures, not narrate every successful loop iteration.
5. Use dependency-aware verification: invalidate checks when relevant geometry, poses, sources or checker code changes. Reuse evidence only when all relevant input hashes and scope remain valid. Run the full integration suite at coherent checkpoints, with the same acceptance thresholds. Never drop motion, flow, contact or visual checks merely to reduce token usage.
6. Consolidate reusable parametric part families and check helpers. Reuse verified geometry mechanisms and export routines, not unverified production dimensions. One integration owner avoids overlapping edits and repeated reconciliation.
7. Worker handoffs report changed files, source facts versus assumptions, validation report paths, unresolved failures and integration instructions. Send interim messages for consequential findings, ownership changes or blockers; avoid repeated unchanged status exchanges.

## Measure before revising the budget

Use the next three bounded assemblies as a pilot. Record root plus worker tokens, cache mix and standard-rate equivalent cost, as well as completed scope, source-backed dimensions, visual review, test coverage and rework. Compare with similarly complex prior work; raw part count is not a quality measure. Keep reasoning quality and acceptance criteria unchanged.

A target of 40–60% lower model cost is an unproven workflow hypothesis. Holding all other usage fixed, cutting cached history by 50% would change the recorded $985.96 to $619.12; cutting it by 75% would produce $435.71. These are arithmetic sensitivity scenarios, not replay measurements: smaller contexts may change cache hit rates, output usage and retrieval overhead. The prior whole-truck forecast remains a low-confidence allowance until the pilot supplies evidence.

Prompt caching is already effective at about 98.1% of input. Preserve stable task prefixes within bounded jobs; indiscriminate compaction can trade cheaper cached tokens for more expensive fresh tokens.
