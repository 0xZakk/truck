## Ranked revision options

1. **Best evidence path:** obtain a dimensioned applicable casting/installed measurement locating the main terminal hole, pan21 axis and recess depth relative to the crank axis and rear flange. Register both interfaces together and preserve the observed seven-hole topology. This would constrain the presently independent estimates. No such measurement is currently available.
2. **Next defensible estimated contract:** revise pan21 location and/or its exterior support form as a coordinated pan/gasket/cover change, retaining a complete female wall/floor and actual screw, washer, seat and tool access. Its X/Y/Z and R10 exterior stock have weaker source support than the main hole pattern. The actual required source female envelope must remain protected; excess R10 stock may only be reconsidered through an explicit functional wall/strength assumption, never silently erased. No specific replacement coordinates are proposed from current evidence.
3. **Secondary registration study:** re-evaluate the whole seven-hole similarity registration with an independently measured scale or crank-to-flange datum. Current pixel sensitivity already shows large terminal shifts and unbounded systematic parallax. Moving only main station1 would distort the source hole pattern; moving the whole pattern affects all seven seats, gasket, land, gear clearance and pan corridor, requiring coordinated revalidation.
4. **Hardware-specific option only after evidence:** a different head envelope, station-specific bolt length, or documented service-tool path could resolve interference. The current R8.75 head andR10.5 axial envelope are estimates; the1986 source supplies none of these dimensions. It cannot justify clipping the head/tool or selecting a convenient shorter bolt.
